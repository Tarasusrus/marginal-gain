НЕСИММЕТРИЧНЫЙ ПОРОГ (Elkan 2001, Теорема 1)
  Цена лишнего удержания: место и токены в бюджете подачи -> C_fp.
  Цена лишнего выброса: безвозвратная потеря -> C_fn.
  Оптимальный порог по вероятности: p* = C_fp / (C_fp + C_fn).

  C_fn/C_fp  p*         какой доле повтора соответствует      
  1:1        0.5000     держим всё, где шанс повтора выше 50.0%
  3:1        0.2500     держим всё, где шанс повтора выше 25.0%
  5:1        0.1667     держим всё, где шанс повтора выше 16.7%
  10:1       0.0909     держим всё, где шанс повтора выше 9.1%
  20:1       0.0476     держим всё, где шанс повтора выше 4.8%
  50:1       0.0196     держим всё, где шанс повтора выше 2.0%

  Наблюдаемые доли повтора по корзинам давности (см. выше) дают, при каком пороге
  какая корзина ещё проходит. Пример при C_fn/C_fp = 10:1, p* = 0.0909:
    давность 0..1     доля 0.269 -> ДЕРЖИМ
    давность 1..2     доля 0.000 -> в отставку
    давность 2..4     доля 0.111 -> ДЕРЖИМ
    давность 4..7     доля 0.000 -> в отставку
    давность 7..14    доля 0.080 -> в отставку
    давность 14..30   доля 0.000 -> в отставку
    давность 30..60   доля 0.000 -> в отставку

  ВАЖНО: доли выше измерены на 29 положительных из 386. ДИ Уилсона по корзинам
  перекрываются почти везде, кроме крайних. Порог, выведенный из них, тоже с ДИ.
